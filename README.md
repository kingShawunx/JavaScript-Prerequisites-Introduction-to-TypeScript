# JavaScript and TypeScript Assignment

This assignment covers JavaScript prerequisites for React and introductory TypeScript: arrow functions, destructuring, spread syntax, template literals, array methods, conditional expressions, ES modules, basic types, typed functions, interfaces, arrays, and union types.

## File structure

Java ass/
├── README.md
├── JavaScript Prerequisites/
│   ├── index.js       # ES module imports and utility examples
│   ├── package.json   # Enables ES modules in Node.js
│   ├── part1.js       # JavaScript language exercises
│   └── utils.js       # Named exports and currency formatter
└── Introduction to TypeScript/
    └── part2.ts       # TypeScript exercises


## Run the JavaScript files

Install Node.js if it is not already available. From the `JavaScript Prerequisites` folder, run:

node index.js
node part1.js


The TypeScript source can be checked with `tsc --noEmit part2.ts` when the TypeScript compiler is installed. The examples use illustrative frontend/backend technologies, product data, and a user profile because those values were not included with the supplied assignment text.
